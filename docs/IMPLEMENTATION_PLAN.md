# خطة تنفيذ VOLTEX

قيد العمل: كتابة ومراجعة مصدرية فقط؛ لا تشغيل، لا تثبيت، لا تحميل، ولا تطبيق migrations. لا تعني علامة إنجاز الكود أنه اجتاز اختبارات تشغيلية.

## قرارات التنفيذ

- مؤسسة واحدة وثلاثة أدوار. الأدمن يدير الحسابات والتكليفات. المروّج يقرأ ويعدّل سجلاته المسموح بها فقط. المشرف يعمل على المروّجين المسندين إليه؛ يمكن إسناد فريق عبر الفروع.
- اعتماد مسار الخادم الحالي الذي يخصم المبيعات من المخزون، مع سعر من الكتالوج ومعاملة ذرية. توضيح الفرق عن التجربة المحلية عند الربط.
- إلغاء البيع للمشرف المسؤول أو الأدمن فقط؛ يحتفظ بالسجل ويعكس المخزون والنقاط مرة واحدة.
- الجرد ملاحظة لا تغيّر الرصيد. طلب النقل يتطلب مصدرًا ويخصم منه ويضيف للوجهة معًا.
- بيانات التجربة مستقلة تمامًا عن الحساب الحقيقي. لا تخزين لكلمة المرور أو refresh token في AsyncStorage. أي جلسة حقيقية يجب ألا تفتح صفحات البيانات التجريبية على أنها بيانات الخادم.

## مراحل العمل بالترتيب

1. إصلاح UUID/Decimal/Enum وردود الأخطاء، مطابقة ORM/migrations، الجرد وعكس النقاط والسعر.
2. توحيد نطاق الموارد وصلاحيات المستخدمين والمبيعات والطلبات والصور والمهام والتقارير. حماية تغييرات التكليف والجلسات.
3. معاملات المخزون والمراجعات، منع تكرار الإرسال، سجل التدقيق والإشعارات، استكمال النقل وتصحيح الطلب.
4. إصلاح قاعدة الاختبار المعزولة وكتابة حالات regression دون تشغيلها. مطابقة عقد API بالكود.
5. طبقة API في الهاتف وحساب حقيقي منفصل، جلسات آمنة وتجديد وخروج واستعادة كلمة مرور؛ ثم ربط الكتالوج والمبيعات والمخزون وباقي المجالات تدريجيًا.
6. استكمال واجهات إجراءات الخادم: تنفيذ طلب/نقل/تصحيح/إلغاء، إدارة الجلسة، عرض الفروع، صفحات البيانات الحقيقية وحالات التحميل والفشل.
7. طابور offline، إعادة الإرسال وحل التعارضات، صور محمية، تحديث المحتوى والتقارير والمكافآت.
8. إعداد ملفات CI والبناء والبيئات والنسخ الاحتياطية والتوزيع؛ تنفيذها متوقف على السماح بالتشغيل لاحقًا.

## شروط التسليم لكل مرحلة

- كود وربط صريح، وليس دوال غير مستدعاة أو واجهات تعرض نجاحًا وهميًا.
- تحديث العقد والتوثيق، وتسجيل ما هو مكتوب وما لم يتم التحقق منه.
- الحفاظ على الواجهات والثيم والبيانات المحلية الحالية.
- مراجعة المصدر ومسارات الاستدعاء بعد التعديل؛ الاختبارات المكتوبة تظل غير منفذة.

## الحالة

بدأ التنفيذ بإصلاح أساس الخادم؛ سجل التقدم التفصيلي سيضاف عند إتمام التعديلات ومراجعتها.
